博客系统 · Markdown 多用户博客

一个完整的前后端分离博客：注册登录、Markdown 写作、分类与搜索、作者权限隔离。 前端负责内容呈现与写作体验，后端用 Express 提供 REST 接口，数据落在 MySQL。

React 19 TypeScript Vite Tailwind 4 Express MySQL JWT

核心功能

  • JWT 登录（有效期 7 天）+ bcrypt 加密存储密码，支持注册 / 退出
  • 文章列表分页，每页 10 条，支持分类筛选
  • 按标题与正文关键词搜索
  • 详情页自动累加浏览数
  • 写作页支持新建 / 编辑，仅作者本人可改可删
  • 封面图通过 multer 上传，限制 5MB 且仅图片类型
  • 个人中心可修改邮箱与头像

页面结构

/ /post/:id /write /write/:id /profile /login /register

数据表

users账号、密码哈希、邮箱、头像
categories分类名称，接口返回各分类文章数
posts标题、正文、封面、标签（JSON）、作者外键

技术实现

  • 前端 React 19 + TypeScript + Vite，路由用 react-router
  • Markdown 渲染：react-markdown + remark-gfm（支持表格、任务列表）
  • 接口统一走 /api，开发环境由 Vite 代理到 3001 端口
  • 后端 Express 4 + mysql2，鉴权中间件校验 JWT 后注入当前用户
  • 上传接口用 multer 做类型与体积双重校验
  • 文章标签以 JSON 字段存储，配合索引加速分类查询

本地二次开发（可选）

# 1. 准备 MySQL 并建库，写入 .env
# 2. 后端
cd server
npm install
npm run seed   # 写入演示账号 demo / 123456
npm run dev    # http://localhost:3001

# 3. 前端
cd client
npm install
npm run dev    # http://localhost:5173

项目已部署在线上演示环境，演示账号 demo / 123456； 上方命令仅用于本地二次开发，源码位于 E:\plant\blog。

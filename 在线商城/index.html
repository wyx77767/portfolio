极简商城 · 素白美妆商店

18 件单品、5 个分类的极简美妆商城。界面克制留白，重点放在「浏览 → 加购 → 结算 → 订单」 这条完整交易链路上，并在后端处理库存并发、订单快照与状态流转。

核心功能

  • 分类、品牌、价格区间三个维度的组合筛选
  • 关键词搜索 + 4 种排序（默认 / 价格升降 / 上新）
  • 折扣专栏按原价与原价差自动计算折扣力度
  • 购物车同一商品合并累加，数量与库存联动
  • 收货地址支持默认地址互斥切换
  • 下单在事务中条件扣减库存，避免超卖
  • 订单号由「M + 时间戳 + 4 位随机数」生成，冲突自动重试
  • 订单内保存商品名、图、单价快照，历史订单不受改价影响

页面结构

/ /sale /product/:id /cart /checkout /orders /orders/:id /addresses /login /register

数据表

products名称、分类、品牌、价格、原价、库存
cart_items用户购物车条目
addresses收货地址，默认地址唯一
orders / order_items订单主表与商品快照
users账号与加密密码

技术栈

  • 前端 React 19 + TypeScript 5.7 + Vite 6，纯 CSS 手写，无 UI 框架
  • 三个 Context：Auth 鉴权、Cart 购物车、Toast 轻提示
  • 后端 Express 4 + knex，默认 SQLite（内置 muse.db），可切 MySQL
  • 参数校验用 zod，密码 bcrypt，登录态 JWT
  • 服务启动自动建表并写入 18 件商品与演示账号

本地二次开发（可选）

# 后端（默认 SQLite，开箱即用）
cd server
npm install
npm run dev    # http://localhost:3101

# 前端
cd client
npm install
npm run dev    # 演示账号 demo / demo1234

MIST-ASK · Q&A COMMUNITY

问答社区 · 雾问

一个积分驱动的问答社区：提问消耗积分、回答与采纳获得积分，点赞有正负反馈。 重点不在「能发帖」，而在积分规则、事务一致性与防重复操作这些容易被忽略的细节。

React 19 Vite 7 Express SQLite JWT Markdown GFM

核心功能

  • 最新 / 热门 / 未解决三种列表视图
  • 标签筛选 + 关键词搜索 + 分页（每页 8 条）
  • 提问支持 Markdown（GFM）书写，详情页渲染
  • 回答可被提问者采纳，采纳后标记已解决
  • 点赞与点踩，禁止给自己投票
  • 积分榜 TOP 用户排名
  • 个人主页展示提问、回答与积分变化

积分规则

+20注册即得初始积分
−5发布提问
+10提交回答
+30回答被采纳
±5被点赞 / 被点踩

数据与一致性

users账号、积分余额、加密密码
questions标题、正文、标签、状态、浏览量
answers回答内容、是否被采纳
votes投票记录，唯一索引防重复

关键处理

  • 采纳与积分变更放在同一事务里，避免只改一半
  • votes 表 (user_id, target, target_id) 加唯一索引，重复点赞直接被数据库拒绝
  • 点赞数等冗余计数随事务同步更新

页面结构

/ /questions/:id /ask /login /register /users/:id
